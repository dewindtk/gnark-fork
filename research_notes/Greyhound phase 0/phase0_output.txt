== 2. Invertibility bound
Claim (LS18, ePrint 2017/523, Cor. 1.2 specialised to k = d): if X^d+1 splits into k
factors mod p, any y with 0 < ||y||_2 < p^(1/k) is invertible in Z_p[X]/(X^d+1).
Re-derivation for k = d: if y is not invertible, y(w) = 0 mod p for some root w, so y lies
in a prime ideal P of norm p, hence p | N(y) and N(y) != 0, so |N(y)| >= p. By AM-GM and
||sigma(y)||_2^2 = d * ||y||_2^2 (power-of-two cyclotomic), |N(y)| <= ||y||_2^d. So
||y||_2 >= p^(1/d). Infinity-norm form: ||y||_2 <= sqrt(d)*||y||_inf, giving
||y||_inf < p^(1/d)/sqrt(d).
p=   257 d=4: bound p^(1/d) =  4.004; shortest non-invertible ||y||_2 =  4.123 OK  e.g. y = (-4, -1, 0, 0)
p=   257 d=8: bound p^(1/d) =  2.001; shortest non-invertible ||y||_2 =  2.236 OK  e.g. y = (-2, -1, 0, 0, 0, 0, 0, 0)
p=    97 d=4: bound p^(1/d) =  3.138; shortest non-invertible ||y||_2 =  3.606 OK  e.g. y = (-3, -2, 0, 0)

== 4. Module-SIS security, core-SVP (ADPS16, ePrint 2015/1092)
Model: BKZ-b on an m-column sublattice reaches length delta(b)^m * q^(n/m) (n = kappa*d rows);
delta(b) from Chen (thesis 2013); cost 2^(0.292 b) classical [BDGL16], 2^(0.265 b) quantum [Laa15].
Secure at bound beta iff the best length over m exceeds beta. Ignores l_inf, dimension-for-free and
the full lattice-estimator; it is the methodology the Greyhound reference README quotes.
128-bit quantum core-SVP -> b = 484, log2 delta = 0.00502
Rows n*log2 q needed (bits per commitment), = (log2 beta)^2 / (4 log2 delta):
